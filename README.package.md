# peiosutils package

This package is part of [peiosutils](https://github.com/peios/peiosutils),
a hard fork of [uutils/coreutils](https://github.com/uutils/coreutils)
maintained for Peios.

Individual commands in this fork still use the `uu_*` crate prefix until
they have been peiosified, at which point they are renamed to `pu_*`.
See the [top-level README](../../README.md) for the full peiosification
convention and status.
