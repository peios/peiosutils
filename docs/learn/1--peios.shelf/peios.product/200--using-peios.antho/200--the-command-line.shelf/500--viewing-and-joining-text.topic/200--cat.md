`cat` copies bytes from files into one output stream. Use it when the order of
whole files matters, rather than the order of individual lines.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Follow these steps in the same shell:

1. Create the example input:

   ```sh
   printf 'Opening\n' > opening.txt
   ```

2. Create the example input:

   ```sh
   printf 'Details\n' > details.txt
   ```

3. Read the selected file contents:

   ```sh
   cat opening.txt details.txt > report.txt
   ```

4. Read the selected file contents:

   ```sh
   cat report.txt
   ```

## Check the result

The report contains `Opening` followed by `Details`. The input files remain
unchanged.

## Inspect text without changing it

Use `cat -A report.txt` to display line endings, tabs, and other nonprinting
characters. This changes the display, not the file. Use `cat -n report.txt`
when line numbers help you discuss a passage.

A name of `-` reads standard input. With no filenames, `cat` also reads
standard input. Redirecting output to an input file truncates that file before
`cat` reads it, so always use a different output name.

See `cat(1)` for the complete options and status contract.
