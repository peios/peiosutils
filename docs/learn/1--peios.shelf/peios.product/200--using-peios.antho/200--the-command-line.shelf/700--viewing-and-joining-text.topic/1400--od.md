`od` displays bytes as numbers or characters. Use it to distinguish a newline,
a zero byte, and ordinary text without asking a terminal to render those bytes
directly.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Follow these steps in the same shell:

1. Create the example input:

   ```sh
   printf 'AB\n' > sample.bin
   ```

2. Run the next command:

   ```sh
   od -An -tx1 sample.bin
   ```

## Check the result

The output contains hexadecimal bytes `41 42 0a`: `A`, `B`, and a newline.

## Separate the view from the data

`-tx1` shows one byte per hexadecimal value. `-An` hides the offset column.
Other views group bytes into integers or floating-point values, which
introduces byte-order and representation choices.

Repeated output rows can be collapsed to `*`; use `-v` when you need every row
displayed. A byte skip changes the starting point, while a byte count limits
how much is read. Neither option changes the source file.

See `od(1)` for the complete options and status contract.
