`ln` creates links. A symbolic link stores a target path; a hard link adds
another name for the same filesystem object.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Follow these steps in the same shell:

1. Create the example input:

   ```sh
   printf 'Draft\n' > report.txt
   ```

2. Run the next command:

   ```sh
   ln -s report.txt latest
   ```

3. Run the next command:

   ```sh
   readlink latest
   ```

4. Read the selected file contents:

   ```sh
   cat latest
   ```

## Check the result

The link stores `report.txt`, and reading through it prints `Draft`.

## Choose identity or indirection

A hard link shares the underlying object, including its data and security.
Removing one name does not remove another hard link. Hard links normally
cannot cross filesystems.

A symbolic link has its own identity and stores a path. A relative target is
resolved from the directory containing the link. The target can be missing, or
can later be replaced by another object.

Avoid overwrite options until you have checked what the destination names.
`ln(1)` defines destination-directory handling and replacement policies.
