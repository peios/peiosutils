`df` reports filesystem-level space usage. Use it to understand how much space
is available where a file would be created.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Run the command:

```sh
df -h .
```

## Check the result

The output includes the filesystem containing the working directory, with
total, used, and available space in scaled units.

## Distinguish capacity from directory contents

Available space is not necessarily total space minus visible file sizes.
Reserved space, metadata, snapshots, and files still open after removal can
affect the totals.

`du` answers a different question: how much space a walk of named files
accounts for. A discrepancy between `df` and `du` is a reason to inspect the
accounting model, not proof that either command is wrong.

See `df(1)` for the complete options and status contract.
