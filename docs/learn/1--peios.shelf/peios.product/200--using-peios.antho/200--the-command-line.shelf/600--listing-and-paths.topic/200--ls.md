`ls` shows directory entries. A short listing answers which names exist; a
long listing adds metadata that helps distinguish those entries.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Follow these steps in the same shell:

1. Create the example directory:

   ```sh
   mkdir sample-directory
   ```

2. Create the example input:

   ```sh
   printf 'Draft\n' > sample-directory/report.txt
   ```

3. Run the next command:

   ```sh
   ls -l sample-directory
   ```

## Check the result

The listing includes `report.txt`. Its size is 6 bytes; timestamps and owner
information depend on the environment.

## Read metadata with the right authority

On Peios, access decisions use security descriptors and tokens. The listing's
ownership and execution markers summarize selected metadata; they are not a
complete account of access. Use `sd show` to inspect a file's security
components.

A directory entry is a name, and names can contain spaces, tabs, or newlines.
Do not parse a human-oriented `ls` listing as a filename protocol. Choose a
tool that preserves filenames separately from display text.

Hidden names begin with a dot. `-a` includes them; `-A` excludes the special
`.` and `..` entries. Sorting, color, timestamps, and link handling have
separate controls described in `ls(1)`.
