`seq` writes a sequence of numbers. Use an explicit start, step, and end when
the sequence's shape matters.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Run the command:

```sh
seq 2 2 8
```

## Check the result

The output is `2`, `4`, `6`, and `8`, on separate lines.

## Choose numeric and display rules separately

A separator or format changes the output layout. It does not change the
sequence's numeric meaning. Floating-point steps can expose representation
limits; use integer steps when exact integer progression is required.

Do not assume that a command consuming the output expects one number per line.
Match its input format explicitly.

See `seq(1)` for the complete options and status contract.
