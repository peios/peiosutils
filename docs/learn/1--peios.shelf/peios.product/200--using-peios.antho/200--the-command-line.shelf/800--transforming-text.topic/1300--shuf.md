`shuf` rearranges input lines randomly. It can also select a smaller sample
when you do not need every entry.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Follow these steps in the same shell:

1. Create the example input:

   ```sh
   printf 'Aster\nBirch\nCedar\n' > names.txt
   ```

2. Run the next command:

   ```sh
   shuf names.txt
   ```

## Check the result

Each of the three names appears once, in an order that can vary between runs.

## Decide whether repetition is allowed

Without repetition, a sample cannot contain more distinct entries than its
input. Repetition is an explicit option and can produce the same line more
than once.

A recorded random-source stream can make a shuffle reproducible if it contains
enough data. A predictable source is useful for testing, not for
security-sensitive random choices.

See `shuf(1)` for the complete options and status contract.
