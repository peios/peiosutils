`fmt` rearranges words into lines of a chosen width. Use it for plain-text
paragraphs, not for code or formats where line breaks carry structure.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Follow these steps in the same shell:

1. Create the example input:

   ```sh
   printf 'Aster and Birch grow beside the path. Cedar grows nearby.\n' > notes.txt
   ```

2. Run the next command:

   ```sh
   fmt -w 30 notes.txt
   ```

## Check the result

The sentence wraps into shorter lines. Its words remain in order.

## Protect structured text

Paragraph boundaries, indentation, and prefixes affect reflow. A line width is
a layout goal; a word longer than that width cannot be split into shorter
words safely.

Use `fold` when physical line wrapping matters more than paragraph structure.
Keep tables, code, and markup out of a prose-only reflow unless you have
checked the output.

See `fmt(1)` for the complete options and status contract.
