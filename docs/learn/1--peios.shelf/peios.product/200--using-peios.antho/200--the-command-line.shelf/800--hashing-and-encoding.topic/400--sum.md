`sum` calculates a legacy checksum and a block count. Use it when another
system or data format specifically requires that checksum.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Follow these steps in the same shell:

1. Create the example input:

   ```sh
   printf 'Release notes\n' > release.txt
   ```

2. Run the next command:

   ```sh
   sum release.txt
   ```

## Check the result

The output contains a checksum, a block count, and `release.txt`.

## Do not use the checksum as identity

The checksum has too few possible values to identify arbitrary files securely.
Different data can share the same result. Its block count also depends on the
selected algorithm's unit.

Use a cryptographic digest such as SHA-256 when creating a new integrity
workflow, and authenticate the expected digest separately. `sum(1)` defines
the older algorithm variants.
