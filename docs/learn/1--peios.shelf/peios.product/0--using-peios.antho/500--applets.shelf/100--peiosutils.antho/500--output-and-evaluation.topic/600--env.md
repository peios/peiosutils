`env` starts a command with an adjusted environment. The setting applies to
that command and its descendants, not to the shell that invoked `env`.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Run the command:

```sh
env PEIOS_EXAMPLE=ready peiosutils printenv PEIOS_EXAMPLE
```

## Check the result

The output is `ready`. The invoking shell's environment is unchanged.

## Environment is input, not authority

Environment variables affect how programs find files, select languages, and
configure behavior. A cleared environment can improve reproducibility, but it
is not a security sandbox.

Without a command, `env` prints environment entries. Avoid publishing that
output indiscriminately because environments can contain credentials or other
private values. See `env(1)` for clearing variables and command lookup.
