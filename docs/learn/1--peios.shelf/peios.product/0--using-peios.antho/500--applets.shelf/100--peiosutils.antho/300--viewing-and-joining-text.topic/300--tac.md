`tac` reads records from the end of its input toward the beginning. This helps
you inspect the last entries first while keeping each line readable.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Follow these steps in the same shell:

1. Create the example input:

   ```sh
   printf 'first\nsecond\nthird\n' > sequence.txt
   ```

2. Run the next command:

   ```sh
   tac sequence.txt
   ```

## Check the result

The output is `third`, `second`, and `first`, on separate lines.

## Choose record boundaries

A newline ends a record by default. A custom separator lets you reverse other
record formats. Keep the separator attached to the correct side of each
record; changing that choice can change where delimiters appear.

`tac` reverses each input file separately. It does not combine several files
into one chronological history.

See `tac(1)` for the complete options and status contract.
