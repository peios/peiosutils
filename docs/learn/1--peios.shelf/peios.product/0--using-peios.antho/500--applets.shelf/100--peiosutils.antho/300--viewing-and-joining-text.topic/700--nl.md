`nl` prints a numbered view of text. Numbering can help you refer to a
particular line without editing the original file.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Follow these steps in the same shell:

1. Create the example input:

   ```sh
   printf 'Opening\n\nDetails\n' > notes.txt
   ```

2. Run the next command:

   ```sh
   nl notes.txt
   ```

## Check the result

`Opening` and `Details` receive consecutive numbers. The blank line stays
blank.

## Choose what receives a number

Use `nl -ba notes.txt` to number blank lines too. The default numbers only
nonempty body lines. Number width, separator, and starting value affect the
printed view; they do not change the input.

`nl` also recognizes special logical-page delimiters that can restart
numbering or select header, body, and footer rules. If those delimiters can
appear in your data, review `nl(1)` before treating the result as a simple
line counter.
