`wc` counts input. The right count depends on whether you care about text
records, words, or the storage occupied by the input bytes.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Follow these steps in the same shell:

1. Create the example input:

   ```sh
   printf 'Aster Birch\nCedar\n' > names.txt
   ```

2. Run the next command:

   ```sh
   wc -l -w -c names.txt
   ```

## Check the result

The counts are 2 lines, 3 words, and 18 bytes, followed by the filename.

## Count the intended unit

The line count counts newline characters. A final unterminated line can
contain text without adding another newline to that count.

Byte and character counts differ for multibyte encodings. Word boundaries also
depend on whitespace rules. Choose an explicit count when another program will
read the result rather than relying on the default columns.

See `wc(1)` for the complete options and status contract.
