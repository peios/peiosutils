`sync` requests writeback of pending filesystem changes. It is useful at an
explicit durability boundary, but it does not validate the meaning of the data
being written.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Run the command:

```sh
sync
```

## Check the result

The command returns without output when the request completes successfully.

## Distinguish data completion from correct content

Writeback does not make a partially constructed file complete, check a
checksum, or combine several file updates into one transaction. Those
properties belong to the writer's design.

Device and filesystem behavior still matter for durability. `sync(1)` defines
file-specific and filesystem-specific request modes.
