`comm` compares two sorted files. Its three output columns distinguish lines
found only in the first file, only in the second, and in both.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Follow these steps in the same shell:

1. Create the example input:

   ```sh
   printf 'Aster\nBirch\n' > first.txt
   ```

2. Create the example input:

   ```sh
   printf 'Birch\nCedar\n' > second.txt
   ```

3. Run the next command:

   ```sh
   LC_ALL=C comm -12 first.txt second.txt
   ```

## Check the result

Only `Birch` appears. `-12` hides the two columns of unmatched lines.

## Establish the ordering first

Sort both files with the same locale and comparison rules before comparing
them. Use `sort -u` first if your task treats repeated lines as one set
member. `comm` compares lines, not parsed records or file contents behind the
names in a list.

Selecting another column combination lets you find additions or removals. See
`comm(1)` for the column switches and order-checking behavior.
