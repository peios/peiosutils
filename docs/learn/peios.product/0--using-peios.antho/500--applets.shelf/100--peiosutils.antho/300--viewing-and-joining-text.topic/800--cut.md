`cut` selects fields or positions from each input line. Use field selection
when a simple delimiter separates the values you need.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Follow these steps in the same shell:

1. Create the example input:

   ```sh
   printf 'name:count\nAster:3\nBirch:5\n' > counts.txt
   ```

2. Run the next command:

   ```sh
   cut -d : -f 1 counts.txt
   ```

## Check the result

The output contains `name`, `Aster`, and `Birch`, one per line.

## Match the data format

A delimiter is a character separator, not a quoting rule. `cut` does not parse
quoted comma-separated records or escaped delimiters. Use a parser for those
formats.

By default, a line without the delimiter passes through unchanged. Add `-s` if
such lines should disappear. Byte positions count bytes rather than visual
columns, so they can split encoded characters.

See `cut(1)` for the complete options and status contract.
