`join` combines records that share a key. Unlike `paste`, it uses the key's
value rather than the line's position to decide which records match.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Follow these steps in the same shell:

1. Create the example input:

   ```sh
   printf 'Aster 3\nBirch 5\n' > counts.txt
   ```

2. Create the example input:

   ```sh
   printf 'Aster green\nBirch silver\n' > colors.txt
   ```

3. Run the next command:

   ```sh
   LC_ALL=C join counts.txt colors.txt
   ```

## Check the result

The output is `Aster 3 green` followed by `Birch 5 silver`.

## Sort with the same rules

Both inputs must be sorted on the join field using compatible comparison
rules. Set the same locale when sorting and joining. If you choose another
field or delimiter, use matching settings in both operations.

The default prints only matching records. Options can retain unmatched records
and select output fields. Duplicate keys can produce more than one output row,
so a join does not establish that a key is unique.

See `join(1)` for the complete options and status contract.
