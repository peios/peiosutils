`tty` reports the terminal associated with standard input. A script can use
its status to distinguish terminal input from a pipe or file.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Run the command:

```sh
tty
```

## Check the result

In an interactive terminal, the output names that terminal. Otherwise the
command reports that standard input is not a terminal and exits nonzero.

## Check the correct stream

This command inspects standard input, not every stream in the process. A
program can read a pipe while writing to a terminal, or the reverse.

Use the silent mode when only the status matters. `tty(1)` defines the status
values and display behavior.
