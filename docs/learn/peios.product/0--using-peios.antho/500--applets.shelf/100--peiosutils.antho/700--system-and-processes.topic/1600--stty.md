`stty` reads or changes terminal settings. These settings control behavior
such as local echo, line buffering, and special control characters.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Run the command:

```sh
stty -a
```

## Check the result

With terminal input, the output describes the terminal's settings. The query
itself does not change them.

## Restore settings after temporary changes

A program that changes terminal handling should restore the saved state even
when it fails. Leaving echo or line processing changed can make the next shell
interaction confusing.

Use the saved-state form when a script needs to restore the exact prior
settings. A general reset is not necessarily equivalent to that saved state.
`stty(1)` covers terminal selection and setting syntax.
