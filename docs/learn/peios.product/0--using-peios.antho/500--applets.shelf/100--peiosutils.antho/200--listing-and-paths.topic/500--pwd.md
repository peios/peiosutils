`pwd` prints the working directory. A physical path resolves symbolic links; a
logical path can preserve the route used to reach the directory.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Run the command:

```sh
pwd -P
```

## Check the result

The output is an absolute path to your physical working directory.

## Choose the path you intend to use

A shell can provide its own `pwd`. Use `peiosutils pwd -P` when testing this
utility specifically. Logical behavior can use the shell's `PWD` value when
that value is valid.

A printed path is not a persistent handle to the directory. Another process
can rename the directory after the query. Keep a directory handle when
identity across concurrent changes matters.

See `pwd(1)` for the complete options and status contract.
