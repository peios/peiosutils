`rm` removes names from the filesystem. It does not provide an undo operation,
and removing a name is different from erasing all copies of its data.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Follow these steps in the same shell:

1. Create the example input:

   ```sh
   printf 'Disposable draft\n' > disposable.txt
   ```

2. Run the next command:

   ```sh
   rm -i disposable.txt
   ```

## Check the result

Answer the removal prompt only if it names `disposable.txt`. After an
affirmative answer, that name is absent.

## Separate prompts from authorization

The write-protection prompt reflects a write-access check. Permission to
remove the object is a separate access decision. A prompt neither grants
access nor proves that the caller can delete the file.

Recursive removal must be requested explicitly. The root-preservation check is
a safeguard, not a substitute for inspecting the operand. A wrong non-root
directory can still contain valuable data.

Deleting a name does not erase snapshots, backups, other hard links, or
storage remnants. `shred` also has storage-specific limits; neither command is
a universal secure-erasure guarantee.

See `rm(1)` for the complete options and status contract.
