`dd` copies a byte stream with explicit block counts and optional conversions.
It is useful when the copy boundary is a size rather than a line or record.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Follow these steps in the same shell:

1. Create the example input:

   ```sh
   printf 'ABCDEFGH' > source.bin
   ```

2. Run the next command:

   ```sh
   dd if=source.bin of=prefix.bin bs=4 count=1 status=none
   ```

3. Run the next command:

   ```sh
   od -An -tc prefix.bin
   ```

## Check the result

The output displays `A B C D`. The source file retains all eight bytes.

## Treat output selection as a destructive choice

`of=` names the output and can overwrite it. Check that name before using a
device node. A mistake involving a disk is not limited to one ordinary file.

Counts and offsets use the selected block units unless an explicit byte mode
says otherwise. A short read and an end-of-input condition need not mean the
same thing for every source.

Completion means the requested copy operations succeeded; durability requires
the appropriate synchronization behavior. `dd(1)` defines input, output,
conversion, and synchronization flags.
