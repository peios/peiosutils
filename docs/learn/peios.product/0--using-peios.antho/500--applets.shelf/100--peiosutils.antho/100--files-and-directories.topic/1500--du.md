`du` walks files and totals their storage usage. Use it to find which parts of
a tree account for space before choosing what to archive or remove.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Follow these steps in the same shell:

1. Create the example directory:

   ```sh
   mkdir measurements
   ```

2. Create the example input:

   ```sh
   printf 'Sample\n' > measurements/report.txt
   ```

3. Run the next command:

   ```sh
   du -sh measurements
   ```

## Check the result

The output gives one scaled total for `measurements`. Allocation units make
that total larger than the sample's seven bytes on many filesystems.

## Choose allocated or apparent size

Apparent size counts logical file length. Allocated size reflects storage
blocks and can differ for sparse or compressed files. Hard links also need a
counting policy so that multiple names do not accidentally count one object
several times.

Link-following and filesystem-boundary options change what the walk includes.
Check errors: an unreadable subtree makes the measurement incomplete. `du(1)`
defines those choices and depth controls.
