`pr` formats text into pages. It can add headings and arrange columns when you
need a printable or page-oriented view of a file.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Follow these steps in the same shell:

1. Create the example input:

   ```sh
   printf 'Aster\nBirch\nCedar\n' > names.txt
   ```

2. Run the next command:

   ```sh
   pr -t -n names.txt
   ```

## Check the result

The three lines appear with line numbers and without a page heading. The
source file stays unchanged.

## Separate presentation from records

Page headings, blank lines, and columns are presentation data added to the
output. Do not feed that output to a parser expecting the original rows.

The default page layout includes a heading and margins. Use `pr(1)` to choose
page length, width, date formatting, and multi-column layout for your actual
output device.
