`ptx` builds a permuted index: each keyword becomes a lookup entry with its
surrounding text. This helps readers find short passages by a word they
remember.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Follow these steps in the same shell:

1. Create the example input:

   ```sh
   printf 'Aster grows beside Birch\n' > index-source.txt
   ```

2. Run the next command:

   ```sh
   ptx index-source.txt
   ```

## Check the result

The output presents the sentence around its indexed words. The source sentence
is unchanged.

## Choose useful keywords

An index is easier to read when common words do not dominate it. Word
selection and exclusion files let you control that choice. Output formats also
differ in how they represent the surrounding text.

`ptx` produces an index, not a full-text search database. Regenerate the index
when its source text changes.

See `ptx(1)` for the complete options and status contract.
