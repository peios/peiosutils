`tr` translates or removes characters read from standard input. It suits small
character-level changes rather than patterns spanning several characters.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Run the command:

```sh
printf 'aster birch\n' | LC_ALL=C tr 'a-z' 'A-Z'
```

## Check the result

The output is `ASTER BIRCH`.

## Keep the character model explicit

The example deliberately uses the byte-oriented `C` locale and ASCII letters.
Do not assume that an alphabet range performs language-aware case conversion
for every writing system.

Deletion removes matching characters completely. Squeezing collapses runs of
characters from a selected set. Quote sets so that the shell does not
interpret brackets or other pattern characters before `tr` receives them.

`tr` reads standard input; it does not take an input filename operand.

See `tr(1)` for the complete options and status contract.
