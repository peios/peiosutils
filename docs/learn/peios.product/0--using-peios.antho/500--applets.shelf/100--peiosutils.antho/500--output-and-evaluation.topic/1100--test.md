`test` reports whether a condition is true through its exit status. It does
not print a boolean word.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Follow these steps in the same shell:

1. Create the example input:

   ```sh
   printf 'Draft\n' > report.txt
   ```

2. Evaluate the condition and run its matching branch:

   ```sh
   if peiosutils test -f report.txt; then
       peiosutils printf '%s\n' 'Report is a regular file'
   fi
   ```

## Check the result

The output is `Report is a regular file`.

## Avoid ambiguous expressions

Quote variable expansions so that an empty string remains one argument. Prefer
the shell's `&&` and `||` operators to constructing a long ambiguous
expression inside one `test` invocation.

A file test is a momentary observation. It does not guarantee that the same
object will be opened later. Programs that need race-resistant access must
validate the opened object itself.

The `[` spelling needs a final `]` argument. A shell can implement both forms
internally; `test(1)` describes this utility's interface.
