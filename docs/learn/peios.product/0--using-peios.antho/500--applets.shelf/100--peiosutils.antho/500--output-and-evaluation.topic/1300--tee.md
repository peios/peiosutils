`tee` copies standard input to both standard output and named files. It helps
you keep a record without hiding the stream from the terminal or the next
command.

## Before you start

Use a terminal with Peiosutils installed. For examples that create files,
start in a disposable working directory without existing example names.

## Perform the task

Follow these steps in the same shell:

1. Run the next command:

   ```sh
   printf 'Starting\nFinished\n' | tee progress.log
   ```

2. Read the selected file contents:

   ```sh
   cat progress.log
   ```

## Check the result

Both lines appear during the pipeline and again when the saved log is printed.

## Decide whether replacement is intended

The default replaces an existing output file's contents. Use append mode when
you intend to extend an existing log. A filename of `-` names a file; it is
not another spelling of standard output for this command.

New files inherit security from their destination directory. Existing files
keep their security. Choose the directory deliberately when the stream
contains private information.

A failing pipe and a failing regular file have separate output-error policies.
Check the pipeline's status and use `tee(1)` to choose a policy appropriate to
whether every copy must succeed.
